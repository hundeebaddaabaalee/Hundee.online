Seenaa Biyya Iraan

Seenaa Iraan Akka qarroominaa pershiyaa duri. Kan Tate fi yeroo amma kanatii biyyaa iraan kan taatee beekamtuu. qabanee isinfi dhihanee nuufanaa tura. Iraan eenyuu iraan sabaaf sabllamootaa meqaa of keessatii hammataa. biyyii iraan naanoo kamittii argamaa. Kan jedhuu qabanee isinfi dhihanee Biyyii iraan sabaaf sabllamootaa addaalee garagaraa fi afaannotaa gargaraa dubataan heeduu of keessatii kan qabuu tahuus. Isaan keessa saabnii pershiyaa harkaa 100 irraa 61 yoo tahuu biyyaatii kessaatii sabaa irraa guddaa tahudhaan beekamaa. Haa tahuu malee Afaan hojjii ykn afaan walii galla biyyaatii kessaatii dubatamuu afaan pershiyaati jedhamaa. Bareefamnii Quubeen afaan pershiyaa qubee afaan arabaatin kan bareefamuu tahuus. afaan pershiyaa afaanotaa intoo yuruphiyaan keessatii ramadamaan keessa isaa tokko. Sana qofa oson hin tanee afaan pershiyaa beekamtii sabichaa kan callaqisuu yoo tahuu. Afaan pershiyaa afaanotaa gurguddaa Naannoo biyyotaa jiduu galla keessatii Dubatamuu keessa isaa tokko tahuus daangaa iraanitin Alatii biyyotaa afaan pershiyaa keessatii dubatamuu biyyaa akka faganistaanii biyyaa akka tajakistani fi biyyaa uszpakistani keessatii kan dubatamuu tahuu mirkaneefamee Jira Sabnii pershiyaa jiduu galla iraan irraa jalqabee hangaa qarqaraa kaabaa iraanitin kan qubatuu yoo tahuu. Akkasumaa sabiichii kun biyyotaa jiduu galaa irraa jalqabee hangaa qarqaraa biyyotaa eshiyaa keessatii seenaa guddaa kan qabuudhaa. Sabnii pershiyaa hortee sabaa aariyaan jedhamuu irraa kan dhufe yoo tahuu. maqaa pershiyaa jedhamuu goddinaa naanoo kaabaa iraan paarsaa jedhamuu irraa kan mogafamedhaa Sabiichii kun empayarootaa gurgurdaa gargaraa hundeesuudhaan biyyotaa aduunyaa kan bulchaa turan yoo tahuu Fakkenyaf sabnii Aariyaan empayera akka aqmaniya kan akka empaayerri siizaniyaa empayera hundeesuudhaan seenaa aduunyaa keessatii Bara 550 dhalotaa nabi iisaa dura mootiin khoorroshiin guddichii empaayerri pershiyaa hundeesuudhaan haawwasinii pershiyaa harkaa caalaan isani yero amma kanatii amantaa islama shii.aa ishraa ashariyaa kan hordofaani.yoo tahuu Hawasichii kun oson amantaan islama hin dhaqabiin duraa amantaa najuushii jedhamuu kan hordofaa turan tahuu seenaan pershiyaa dubataa Jalaqabaa Horteen sabaa pershiyaa sabaa baladhaa Aariyaan jedhamuu irraa kan dhufe yoo tahuu "Sabnii baldhaan Aariyaan jedhamuu bara 15 dhalotaa nabi iisaa dura qarqaraa naanoo eshiya irraa garaa jiduu galla eshaytii godaanudhaan naanoo jiduu galla biyyotta eeshiyaa keessa walqooduudhaan biyyaa inda fi Afghanistani biyyaa iraan amma fi iraqi keessa kan qubatanidhaa" Hundee Baddaa Baalee
